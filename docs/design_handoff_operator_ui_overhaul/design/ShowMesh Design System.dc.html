Foundation

A restrained, technical system for show-time decisions

Dark graphite is the show-time default. Light is a daylight setup mode. High contrast is a deliberate operator setting for gloves and outdoor night work — never inferred. One blue-green accent carries selection, focus, links, and the single primary action; green, amber, and red are reserved for labelled evidence.

02 — Accent ramp

One accent, five stops, real interaction states

The current build has a single flat accent with a brightness(1.08) filter for hover. That reads as an accident under high contrast. These are five named stops instead.

--accent-bg
Selected row, active tab wash
--accent-border
Quiet edges, dividers in accent context
--accent
Rest: primary action, links, current
--accent-hover
Pointer over
--accent-active
Pressed, and the focus ring base

03 — Evidence colour

Status is a labelled pair, never a colour alone

Every status surface renders a glyph and a word as well as a fill. Retuned so all four tones sit at matched lightness and chroma — the current set has amber reading two steps louder than green.

✓Healthy
--good-fg / bg / border
Observed, current, within threshold
⚠Degraded
--warn-fg / bg / border
Stale, restarting, superseded, conflicted
✕Failed
--bad-fg / bg / border
Observed failure with a stated reason
?Unknown
--unk-fg / bg / border
Unobserved, never collected, signed out

The dashed edge on Unknown is load-bearing. Absent evidence must not be able to borrow the shape of a settled state, in any theme, at any zoom.

05 — Controls

One primary action, and secondary means secondary

34 px on a pointer, 48 px minimum where the shell is touched with gloves. Destructive controls sit physically apart from the save path.

09 — Copy rules

Shorter, and only where it changes a decision

Today

“Authoritative current playback is unavailable. The coordinator could not be read. This does not prove that no external process is running.”

Three sentences to say one thing, and the caveat outweighs the fact.

Proposed

Current run unknown — coordinator unreadable.

A show may still be running.

Fact first, at value weight. The caveat drops to helper size and stays.

  • Label the outcome of a choice, not the field. “Program output group”, not “Audio route selection mode”.
  • Helper text earns its line or it is deleted. If it repeats the label, it goes.
  • Never explain the architecture in a form. ADR reasoning belongs in docs, not beside an input.
  • State the reason literally, then the action. “Agent did not answer in 5 s. Run discovery again.”
