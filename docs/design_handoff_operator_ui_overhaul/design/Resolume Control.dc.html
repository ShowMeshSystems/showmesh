When this page cannot be drawn

No composition

Nothing has been uploaded, so there are no names to address. The grid and the layer table are absent, not empty, and the page says so with a link to upload one. Blackout still works — it addresses nothing.

Not identified

A composition is stored but the coordinator cannot tell that Arena is running that one. Every dispatch would be refused, so the controls are closed with that sentence rather than left live to fail one at a time.

Not permitted

Without resolume:action the whole page is still readable — state, grid, layers, past results — and every control is closed with one line naming the permission. Reads stay open; only the writing closes.
