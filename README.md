# ShowMesh

ShowMesh is an open-source orchestration and observation layer for complex holiday displays built around tools people already use: Falcon Player (FPP), xLights, Resolume, commodity computers, and standard media transports.

ShowMesh coordinates those systems without replacing their timing, sequencing, mapping, or playback strengths.
